Needlepath Digitizer in testing

Open index.html in Chrome, Edge, Firefox or Safari. No internet connection is needed.
Keep the "fonts" folder next to needlepath.html: 12 fonts are built into the page and the other 110 load from that folder.
Export saves a .pes and a .dst file to your Downloads folder.

The fonts come from the Ink/Stitch font library. Each font licence is shown in the app under "Font credits and licences" once the font is used.
