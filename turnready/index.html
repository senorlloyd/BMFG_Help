How to run it on the HX710 (UGS)
  1. Chuck the stock with at least the stick-out shown above.
  2. Set X and Z zero with the 🎯 Touch-off helper. It writes the exact G10 lines for UGS.
  3. Air cut first: the helper has an air-cut option that sets Z so the whole program runs 20 mm in front of the stock.
  4. The program stops at M0 so you can check the tool. Press Resume / Cycle start in UGS.
  5. When it finishes, part off by hand in the parting gap.

The program starts and ends parked: X at the stock radius + 5 mm (outside the bar) and Z 5 mm in front of it. These are measured from your touch-off, so they don't depend on a saved G28 position. X moves out first, then Z, and the spindle only starts once the tool is parked. Tick "Use G28 homing instead" to go back to G28 like the Fusion files.
